---
id: D-37
title: Lighthouse thresholds gate every deployment
useCase: uc2
resolves: []
---

Lighthouse runs during development and in the deployment pipeline, against
thresholds set to green scores. A deployment below them stops. It can go
out by an explicit bypass, and the regression is then logged as a bug.

*Why:* a performance regression is cheapest to fix before it ships, and the
migration ramp compares the new front end with AEM on Core Web Vitals
(Q31). The bypass keeps an urgent fix from waiting on a score, without
letting the regression go unrecorded.
