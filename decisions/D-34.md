id: D-34
title: Globant builds and runs the partner web front end, hosted by EG on AWS
useCase: uc2
resolves: [Q8]
---

The partner web front end is a Next.js and Tailwind application, deployed
with OpenNext to EG's own AWS account. Globant builds it and runs it in production:
deployments, monitoring, dependency and security updates, and incidents. The
AWS account belongs to EG, and Globant deploys to it and runs the front end
there with delegated access.

*Why:* one party owns the front end end to end, and EG keeps the
infrastructure, so a change of supplier is a handover of access rather
than a hosting migration.
