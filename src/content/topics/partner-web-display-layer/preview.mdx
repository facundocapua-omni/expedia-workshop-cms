<h3>How a page is composed</h3>
<p>A page holds sections, and each section holds the blocks. Theme, background, spacing and the section heading live on the section, so no block has to carry them (D-20). Background and theme are roles — light, dark, brand — rather than colours, so a visual non-parity enhancement changes the design tokens and the pages follow.</p>
