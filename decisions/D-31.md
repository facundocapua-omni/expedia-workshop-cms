title: Migration tooling is a scripted, re-runnable pipeline built by Globant
useCase: uc2
resolves: []

Extract from AEM, transform to the target model, load into a Contentful
environment. Entries are upserted by a stable ID derived from the AEM path,
so full rehearsals and delta runs repeat safely. Every run checks counts,
required fields, broken links and a visual diff. Only migrate rows are
loaded; rebuild rows are re-authored. Contentful covers the platform side
and the CMS-30 walkthrough; EG provides AEM access and wave 0 QA.

*Why:* the mapping into the enhanced model is specific to EG, and delta
runs are what keep each content freeze short.
