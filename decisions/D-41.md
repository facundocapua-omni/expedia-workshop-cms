---
id: D-41
title: The component matrix is the line between self-serve and development
useCase: uc2
resolves: []
---

Web Ops build landing pages in Contentful from the whole component library,
using every component in the use cases the component matrix covers,
without a developer. A new component, a use case the matrix does not
cover, or a change to what a component does is new development, and goes
through the Figma flow (D-40). Once built, it joins the matrix and becomes
self-serve.

*Why:* the matrix is already the agreed record of what each component is
and does, so it also answers "can we do this without engineering?"
