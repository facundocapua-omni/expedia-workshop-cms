---
id: D-36
title: Public pages use ISR, private sections use SSR
useCase: uc2
resolves: []
---

Public pages are rendered once, served from cache and regenerated on
demand: a Contentful webhook on publish and unpublish tells the front end
which pages to rebuild. Private sections, whose content depends on who is
signed in, are rendered on the server for every request and never stored
in a shared cache.

*Why:* most of partner web is the same for every visitor and changes only
when an author publishes, so it is refreshed on publish rather than on a
timer. Only what differs per visitor pays for a render on every request.
