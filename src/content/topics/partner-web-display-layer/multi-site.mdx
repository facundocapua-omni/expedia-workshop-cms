<div class="decide">
  <h4><span class="stamp">proposal</span>One Contentful space, one monorepo with an app per site</h4>
  <p>All partner sites share one Contentful space: the same content types, components and assets, with each site's pages and navigation kept apart inside it. The front end is a monorepo with one Next.js app per site, built on shared packages: the component library, the design tokens and the Contentful integration.</p>
