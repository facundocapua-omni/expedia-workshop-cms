<p class="sec-note">The Content Resolution API reports what was served. Every resolution, whichever channel fetched, writes one record to EG's log system, fallbacks included. It is the trace, T, of the <a href="/sessions/proof-point-delivery/#flow">consumption flow</a> in Session 1.</p>

<p>A default copy or a source-locale fallback is never silent: the Content Resolution API records it with the resolution that served it.</p>
