---
id: D-39
title: Authors compose pages in Contentful, with the live preview beside the editor
useCase: uc2
resolves: []
---

A page is built from entries: the page holds sections, and each section
holds the blocks (D-20). While an author edits, the live preview beside the
entry editor shows the page and updates as they type. Clicking an element
in the preview opens the field that holds it.

*Why:* Web Ops compose pages without a developer, within the components the
front end has, and see the result before publishing without leaving the
editor. Content stays structured, so it remains reusable across pages and
channels.
