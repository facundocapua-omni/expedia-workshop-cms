---
id: D-38
title: The live preview is the front end, opened in preview mode
useCase: uc2
resolves: []
---

Contentful's live preview is connected to the partner web front end, which
it opens in preview mode: the same Next.js app, reading unpublished
content, so the page looks as it will once published. Preview mode is not
public and is never cached.

*Why:* previewing with the production front end, rather than a separate
preview application, means what the author approves is what visitors will
see.
